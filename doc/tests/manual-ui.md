# Ручні тест-кейси користувацького інтерфейсу

**Проєкт:** Веб-сайт для персонального фінансового обліку
**Версія документа:** 1.0
**Дата:** 21.10.2026

Кейси перевіряють відповідність інтерфейсу `doc/design-spec.md` і прототипу `doc/ui/prototype.html`. Еталонні значення (кольори, розміри, тексти) беруться зі специфікації; для вимірювань — DevTools (Elements → Computed, Inspect, Device Mode). Якщо не вказано інше, перевірка виконується на ширині 1440 px і 360 px. Колонка **Авто**: автотест, що частково покриває кейс; візуальна відповідність перевіряється лише вручну.
