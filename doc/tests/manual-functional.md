# Ручні функціональні тест-кейси

**Проєкт:** Веб-сайт для персонального фінансового обліку
**Версія документа:** 1.0
**Дата:** 21.10.2026

Формат кейсу, середовища, акаунти і набори даних (D0–D3) описані в `doc/test-plan.md`. Середовище за замовчуванням — staging, браузер — остання версія Chrome на ширині 1440 px. Колонка **Авто** вказує автотест, що покриває кейс; такі кейси вручну виконуються лише перед релізом.

**Загальні очікування для всіх кейсів:** повідомлення українською без технічних кодів (NFR-12); суми у форматі `1 240,50 ₴` (NFR-20); у консолі браузера немає помилок JavaScript.
