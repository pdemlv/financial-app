# Специфікація дизайну користувацького інтерфейсу

**Проєкт:** Веб-сайт для персонального фінансового обліку
**Версія документа:** 1.0
**Дата:** 04.10.2026

---

## 1. Задача дизайну і підхід

Три правила, яких дотримується весь інтерфейс:

1. **Число — головний елемент екрана.** Баланс на головній сторінці набраний найбільшим кеглем на сторінці; заголовки й підписи навмисно стримані.
2. **Рядок, а не картка.** Операції подані суцільною стрічкою з тонкими лініями між днями. Картки з тінями використовуються лише там, де елемент справді відокремлений від потоку (форма у модальному вікні).
3. **Дія на відстані одного натискання.** Кнопка «Додати операцію» присутня на кожному екрані: на комп'ютері — у шапці контенту, на телефоні — у центрі нижньої панелі.

## 2. Кольори

| Токен          | Значення  | Призначення                                      |
| -------------- | --------- | ------------------------------------------------ |
| `--ink`        | `#16201D` | Основний текст, цифри, активні пункти навігації  |
| `--ink-soft`   | `#6B7670` | Другорядний текст, підписи, дати                 |
| `--paper`      | `#F7F7F4` | Фон сторінки                                     |
| `--sheet`      | `#FFFFFF` | Фон контентних областей і модальних вікон        |
| `--line`       | `#E1E4DF` | Лінії, межі полів, розділювачі                   |
| `--plus`       | `#1F7A5A` | Доходи, позитивний баланс, основна кнопка дії    |
| `--plus-soft`  | `#E7F2ED` | Фон позначок і сегментів, пов'язаних із доходами |
| `--minus`      | `#B04A33` | Витрати, від'ємний баланс, небезпечні дії        |
| `--minus-soft` | `#F7EAE6` | Фон позначок, пов'язаних із витратами            |
| `--focus`      | `#1F7A5A` | Обвідка фокуса (2 px, відступ 2 px)              |

**Палітра категорій** (користувач обирає колір із фіксованого набору, щоб діаграми лишалися читабельними): `#1F7A5A`, `#3E7FA6`, `#B04A33`, `#C58A2E`, `#6B5CA5`, `#4C8C6B`, `#A3566F`, `#5E6B73`.

**Правила застосування:**

- колір ніколи не є єдиним носієм змісту: тип операції дублюється знаком «+» або «−» і текстовою назвою категорії (NFR-24);
- контраст основного тексту до фону — не менший за 4.5:1 (NFR-22);
- `--minus` використовується і для кнопки видалення: червоний в інтерфейсі означає «гроші пішли» або «дія незворотна», інших значень не має.

## 3. Типографіка

**Гарнітура:** Manrope (Google Fonts), накреслення 400, 500, 600, 700. Одна гарнітура на весь інтерфейс; цифри скрізь виводяться з `font-variant-numeric: tabular-nums`, щоб суми в стовпчику вирівнювалися розряд під розрядом.

| Роль               | Розмір / міжрядковий        | Накреслення | Застосування                          |
| ------------------ | --------------------------- | ----------- | ------------------------------------- |
| Баланс             | 56 / 60 px, трекінг −0.02em | 700         | Головне число на дашборді             |
| Сума в підсумку    | 28 / 34 px                  | 600         | Доходи й витрати за період            |
| Заголовок сторінки | 22 / 28 px                  | 600         | «Операції», «Категорії», «Аналітика»  |
| Сума в рядку       | 16 / 22 px                  | 600         | Сума операції у списку                |
| Основний текст     | 15 / 22 px                  | 400–500     | Назви категорій, коментарі, поля форм |
| Другорядний        | 13 / 18 px                  | 500         | Дати, підписи полів, підказки         |

На екранах до 480 px баланс зменшується до 40 px, заголовок сторінки — до 19 px, решта лишається без змін.

Підписи набираються реченнєвим регістром. Великі літери суцільним масивом не використовуються — у сумах і коротких українських підписах вони погіршують читання.

## 4. Сітка й відступи

- Базова одиниця — **4 px**; усі відступи кратні їй: 4, 8, 12, 16, 24, 32, 48.
- Максимальна ширина контенту — **880 px**, вирівнювання по лівому краю: текст і суми читаються зверху вниз по одній вертикалі.
- Бічна навігація на комп'ютері — **220 px**.
- Внутрішні відступи контентної області: 32 px на комп'ютері, 16 px на телефоні.
- Радіус заокруглення: 8 px для полів і кнопок, 12 px для модальних вікон, 4 px для дрібних позначок. Рядки списку не заокруглюються — вони є частиною суцільної стрічки.

**Контрольні точки:**

| Точка     | Ширина      | Поведінка                                                                                                                  |
| --------- | ----------- | -------------------------------------------------------------------------------------------------------------------------- |
| Мобільна  | 360–767 px  | Одна колонка, нижня панель навігації з 4 пунктами і центральною кнопкою «+», фільтри згортаються в рядок, що прокручується |
| Планшетна | 768–1023 px | Одна колонка, бічна навігація згорнута до іконок                                                                           |
| Настільна | від 1024 px | Бічна навігація з підписами, підсумки за період у три колонки                                                              |

## 6. Текст в інтерфейсі

- Кнопка називає дію, яка відбудеться: «Додати операцію», «Зберегти зміни», «Видалити». Після виконання повідомлення вживає те саме слово: «Операцію додано».
- Помилки пояснюють причину і спосіб виправлення: «Сума має бути більшою за 0», «Дата не може бути в майбутньому». Технічні коди користувачу не показуються.
- Порожні стани запрошують до дії, а не констатують порожнечу: «Тут з'являться ваші операції. Почніть із першої» і кнопка поруч.
- Суми завжди зі знаком і валютою: `+12 000,00 ₴`, `−1 240,50 ₴`. Дати — у форматі 06.10.2026; у заголовках груп — «6 жовтня, понеділок».

## 8. Доступність і поведінка

| Правило       | Реалізація                                                                                                                                                |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Клавіатура    | Усі дії доступні через Tab і Enter; у модальному вікні фокус замкнений усередині, Esc закриває                                                            |
| Видимий фокус | Обвідка 2 px кольору `--focus` із відступом 2 px; стандартна обвідка не прибирається без заміни                                                           |
| Розмір дотику | Мінімум 44 × 44 px для всіх інтерактивних елементів                                                                                                       |
| Рух           | Переходи тривалістю 150–200 мс лише для відповіді на дію (відкриття вікна, поява повідомлення); при `prefers-reduced-motion: reduce` анімації вимикаються |
| Читачі екрана | Поля мають підписи `label`, діаграми супроводжуються текстовою таблицею значень                                                                           |
| Масштабування | Інтерфейс лишається придатним до використання при збільшенні тексту до 200 %                                                                              |
